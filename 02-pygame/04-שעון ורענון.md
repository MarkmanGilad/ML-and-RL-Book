## ב.4 — שעון, קצב פריימים ורענון המסך

תנועה על המסך נוצרת מרצף תמונות. מספר התמונות המוצגות בשנייה נקרא **FPS — Frames Per Second**. אם הלולאה פועלת מהר ככל האפשר, קצב העבודה עשוי להשתנות בין מחשבים וגם לאורך אותה הרצה. בעזרת שעון אפשר להגביל את הקצב הרצוי.

**המצגת:** [מבוא ל־Pygame](../../../sources/PyGame/2.PyGame.pptx) · [תיעוד התצוגה](https://www.pygame.org/docs/ref/display.html) · [תיעוד השעון](https://www.pygame.org/docs/ref/time.html)

### יצירת השעון והגבלת הקצב

יוצרים את השעון פעם אחת, לפני הלולאה:

<div class="code-panel" dir="ltr">

```python
clock = pygame.time.Clock()
FPS = 60
```

</div>

בסוף כל סיבוב, אחרי הצגת התמונה, מוסיפים:

<div class="code-panel" dir="ltr">

```python
pygame.display.update()
clock.tick(FPS)
```

</div>

הפעולה `tick(60)` ממתינה לפי הצורך כדי להגביל את הלולאה לכ־60 סיבובים בשנייה. היא אינה מבטיחה שהמחשב יצליח להגיע לקצב הזה: אם הכנת פריים נמשכת זמן רב, הקצב בפועל יהיה נמוך יותר. כמו כן, השעון אינו מצייר ואינו מרענן בעצמו את החלון.

### ציור ורענון הן פעולות נפרדות

פעולות הציור משנות את תוכן המשטח בזיכרון. כדי להציג את התוצאה בחלון, קוראים לפעולת רענון לאחר שסיימנו לצייר את הפריים. כך המשתמש רואה את התמונה המורכבת כולה.

| פעולה | שימוש |
| --- | --- |
| `pygame.display.update()` | עדכון כל משטח התצוגה בחלון הרגיל שבו נשתמש |
| `pygame.display.update(area)` | עדכון אזור מסוים; את ייצוג האזור באמצעות `Rect` נלמד בהמשך |
| `pygame.display.flip()` | עדכון התצוגה המלאה |

בדוגמאות שלנו אפשר להשתמש ב־`flip()` במקום `update()` ללא ארגומנטים. אין צורך להפעיל את שתיהן עבור אותו פריים. עדכון חלקי שימושי רק כאשר מנהלים גם את האזורים שהתוכן הקודם שלהם צריך להימחק; בתחילת הלימוד נרענן את כל המסך.

### התוכנית עם שעון

<div class="code-panel" dir="ltr">

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((640, 400))
clock = pygame.time.Clock()
FPS = 60
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    if not running:
        break

    pygame.display.update()
    clock.tick(FPS)

pygame.quit()
```

</div>

**קצב הפריימים אינו מהירות התנועה.** עצם שמתקדם שלושה פיקסלים בכל פריים ינוע מרחק שונה בשנייה אם קצב הפריימים ישתנה. בפרק האנימציה נתחיל בתנועה לפי פריים ונראה גם כיצד משתמשים בזמן שחלף כדי לחשב את מרחק התנועה.
