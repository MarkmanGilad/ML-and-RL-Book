## ב.2 — מבנה הלולאה הראשית

תוכנית שמחשבת סכום יכולה לסיים את פעולתה מיד לאחר הצגת התוצאה. חלון גרפי צריך להישאר פעיל: המשתמש עשוי להזיז את העכבר, ללחוץ על מקש או לבקש לסגור אותו בכל רגע. לכן תוכנית Pygame חוזרת שוב ושוב על פעולות קבועות, עד שמחליטים לסיים. החזרה הזו נקראת **הלולאה הראשית**.

**המצגת:** [מבוא ל־Pygame](../../../sources/PyGame/2.PyGame.pptx)

### לפני הלולאה: מכינים את התוכנית

מחוץ ללולאה מבצעים פעולות שנדרשות פעם אחת: מייבאים את הספרייה, מאתחלים אותה, מגדירים את ממדי החלון ויוצרים אותו. בהמשך נטען כאן גם תמונות וניצור משאבים נוספים.

<div class="code-panel" dir="ltr">

```python
import pygame

pygame.init()
WIDTH, HEIGHT = 640, 400
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("My Pygame Window")
running = True
```

</div>

הקריאה `pygame.init()` מאתחלת את רכיבי הספרייה הזמינים. הפעולה `set_mode()` פותחת חלון במידות שבחרנו ומחזירה משטח תצוגה, שאותו שומרים במשתנה `screen`. הזוג הראשון הוא הרוחב בפיקסלים, והשני הוא הגובה. הכותרת שמופיעה במסגרת החלון נקבעת באמצעות `set_caption()`.

### בתוך הלולאה: חוזרים על פעולות התצוגה

כל סיבוב של הלולאה מכין תמונה אחת של התצוגה — **פריים**. בתוכנית מלאה נטפל באירועים, נעדכן את מצב העצמים, נצייר אותם ונציג את התוצאה. בשלב הראשון אפשר להבין את הרעיון באמצעות לולאה שמעדכנת את המסך בלבד:

<div class="code-panel" dir="ltr">

```python
# A deliberately incomplete first loop
while running:
    pygame.display.update()
```

</div>

זהו שלד לימודי חלקי: הוא אינו משנה את `running` ואינו קורא את האירועים שהחלון מקבל. משום כך החלון עלול להופיע כלא מגיב. אין להשתמש בו כתוכנית הסופית. בפרק הבא נוסיף את הטיפול באירועים ובסגירה; אחריו נוסיף שעון שיגביל את קצב הלולאה.

### החלק הסטטי והחלק הדינמי

נפריד בין פעולות הכנה שמתבצעות פעם אחת לבין פעולות שחוזרות בכל פריים. כך קל לקבוע היכן למקם כל הוראה בתוכנית.

| מחוץ ללולאה — הכנה חד־פעמית | בתוך הלולאה — כל פריים |
| --- | --- |
| אתחול הספרייה ויצירת החלון | קריאת אירועים וטיפול בהם |
| הגדרת מידות, צבעים ומצב התחלתי | שינוי מיקום או מצב בהתאם לקלט |
| טעינת תמונות ויצירת משאבים | ניקוי התצוגה וציור התוכן |
| יצירת שעון, כשנלמד עליו | הצגת הפריים והגבלת קצב הלולאה |

ההבחנה היא בין **הכנת המשאבים** לבין **השימוש החוזר בהם**. גם רקע קבוע עשוי להיצבע מחדש בכל פריים, כדי למחוק ציור של עצם מהמיקום הקודם. לעומת זאת, אין צורך לטעון שוב מהדיסק את אותה תמונה בכל סיבוב.
