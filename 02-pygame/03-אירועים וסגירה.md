## ב.3 — אירועים וסגירת החלון

לחיצה על כפתור הסגירה של החלון היא בקשה מהתוכנית לסיים. כדי שהתוכנית תדע שהבקשה הגיעה, עליה לקרוא את האירועים שממתינים לה. Pygame מרכזת את האירועים בתור; בכל סיבוב של הלולאה אנחנו אוספים אותם ובודקים מה קרה.

**המצגת:** [מבוא ל־Pygame](../../../sources/PyGame/2.PyGame.pptx)

### קוראים את תור האירועים

קריאת התור מאפשרת לתוכנית להגיב למה שקרה מאז הקריאה הקודמת. הפעולה `pygame.event.get()` מחזירה רשימה של האירועים הממתינים ומסירה אותם מהתור. לולאת `for` עוברת על הרשימה, והמאפיין `event.type` מציין את סוג האירוע. אם אין אירועים, הרשימה ריקה והתוכנית ממשיכה לפעולות הבאות.

<div class="code-panel" dir="ltr">

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
```

</div>

הקבוע `pygame.QUIT` מזהה אירוע של בקשת סגירה. אנחנו משנים את `running` ל־`False`, כדי שלא יתחיל סיבוב נוסף של הלולאה הראשית. זהו **תור אירועים**, ולא מחסנית שבה שולפים תחילה את הפריט האחרון שנכנס.

### תוכנית שאפשר לסגור

נשלב את הטיפול בבקשת הסגירה בלולאה הראשית. שמרו את הקוד בקובץ `main.py` והריצו אותו. ייפתח חלון ריק; לחיצה על כפתור הסגירה תסיים את הלולאה ואת השימוש ב־Pygame.

<div class="code-panel" dir="ltr">

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((640, 400))
pygame.display.set_caption("Close the window")
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    if not running:
        break

    pygame.display.update()

pygame.quit()
```

</div>

שימו לב להזחות: לולאת האירועים נמצאת בתוך הלולאה הראשית. הקריאה `pygame.quit()` נמצאת **אחרי** הלולאה הראשית, משום שהיא משחררת את רכיבי Pygame בסיום. הבדיקה `if not running` מונעת ציור נוסף אחרי בקשת הסגירה.

### אירוע סגירה ופעולת סיום

בקשת סגירה והפסקת השימוש בספרייה הן שני שלבים נפרדים. `pygame.QUIT` הוא ערך שמזהה סוג של אירוע. לעומתו, `pygame.quit()` היא פעולה שמסיימת את השימוש ברכיבי הספרייה. היא אינה משנה בעצמה את המשתנה `running` ואינה מסיימת בהכרח את כל תוכנית Python. בדוגמה התוכנית מסתיימת מפני שהלולאה נעצרה ואין אחריה פעולות נוספות.

כעת החלון מגיב, אך הלולאה עדיין פועלת מהר ככל שהמחשב מאפשר. בפרק הבא נוסיף את השעון.


**קוד להורדה:** [הדוגמה המלאה](../assets/pygame/examples/03-demo.py).
