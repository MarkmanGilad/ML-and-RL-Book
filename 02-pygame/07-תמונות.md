## ב.7 — טעינה והצגה של תמונות

במקום לצייר עצם בכל פעם מקווים ומעגלים, אפשר לטעון תמונה ולהציג אותה. לאחר הטעינה גם התמונה היא משטח: אפשר לשנות את גודלה ולהעתיק אותה לחלון באמצעות `blit`, כמו כל משטח אחר.

**המצגת:** [מבוא ל־Pygame](../../../sources/PyGame/2.PyGame.pptx)

### טוענים תמונה לזיכרון

לפני הצגת תמונה, טוענים את הקובץ שלה מהדיסק למשטח בזיכרון. הורידו את [תמונת הדוגמה](../assets/pygame/star.png), שמרו אותה בתיקייה `img` לצד `main.py` ופתחו את תיקיית העבודה ב־VS Code. בקוד נשתמש בנתיב `img/star.png`. זהו נתיב יחסי לתיקייה שממנה התוכנית מורצת.

<div class="code-panel" dir="ltr">

```python
image = pygame.image.load("img/star.png")
```

</div>

מבצעים את הטעינה פעם אחת, לפני הלולאה. טעינה חוזרת מהדיסק בכל פריים אינה נדרשת לתמונה שאינה משתנה.

### מתאימים את הגודל ומציגים

כדי שהתמונה תתאים למקום המיועד לה בחלון, אפשר לשנות את גודלה. הפעולה `scale` מקבלת משטח ומידות חדשות ומחזירה משטח בגודל המבוקש. שומרים את התוצאה במשתנה, ואז מציגים אותה:

<div class="code-panel" dir="ltr">

```python
image = pygame.transform.scale(image, (80, 80))
screen.blit(image, (280, 160))
```

</div>

הגודל כאן הוא 80×80 פיקסלים. הזוג `(280, 160)` קובע את הפינה השמאלית העליונה, ולא את מרכז התמונה. שינוי יחס הרוחב והגובה עלול לעוות את התמונה; בדוגמה המקור והיעד ריבועיים.

### שומרים על הרקע השקוף

לתמונת הכוכב יש פינות שקופות. אחרי יצירת החלון אפשר להשתמש ב־`convert_alpha()` כדי להתאים את המשטח לתצוגה תוך שימור השקיפות. לתמונה אטומה אפשר להשתמש ב־`convert()`; הוא אינו שומר שקיפות נפרדת לכל פיקסל.

<figure>
<img src="../assets/pygame/image.png" alt="תמונת הכוכב מוצגת על רקע כחול כהה; הפינות השקופות אינן מסתירות אותו." width="640">
<figcaption>תמונת הכוכב מוצגת על רקע כחול כהה; הפינות השקופות אינן מסתירות אותו.</figcaption>
</figure>

<div class="code-panel" dir="ltr">

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((640, 400))
clock = pygame.time.Clock()
image = pygame.image.load("img/star.png").convert_alpha()
image = pygame.transform.scale(image, (80, 80))
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    if not running:
        break

    screen.fill((17, 43, 65))
    screen.blit(image, (280, 160))
    pygame.display.update()
    clock.tick(60)

pygame.quit()
```

</div>

אם מתקבלת `FileNotFoundError`, בדקו שהתמונה נשמרה בשם ובתיקייה הנכונים ושהטרמינל נמצא בתיקיית העבודה. אל תקראו לקובץ התוכנית `pygame.py`, כדי שלא יסתיר את הספרייה המותקנת.

[תיעוד טעינת תמונות](https://www.pygame.org/docs/ref/image.html)
