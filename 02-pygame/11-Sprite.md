## ב.11 — ספרייטים: pygame.sprite.Sprite

תמונה נעה כוללת לפחות שני פרטים: המשטח שמציג אותה והמלבן שקובע את מיקומה. במקום להחזיק משתנים נפרדים לכל תמונה, אפשר לאגד אותם במחלקה. ספרייט הוא אובייקט שמייצג עצם גרפי ומרכז את המידע ואת ההתנהגות שלו.

**המצגת:** [Pygame Sprite](../../../sources/PyGame/PyGame%20-%20Sprite.pptx) · [תיעוד ספרייטים](https://www.pygame.org/docs/ref/sprite.html)

### מחלקה היורשת מ־Sprite

ניצור מחלקה שמקבלת תמונה ומיקום מרכז. הבנאי קורא ל־`super().__init__()` כדי לאתחל את מחלקת הבסיס, ושומר את `image` ואת `rect`. מתודת `update()` מעדכנת את המיקום.

<div class="code-panel" dir="ltr">

```python
class MovingImage(pygame.sprite.Sprite):
    def __init__(self, image, center):
        super().__init__()
        self.image = image
        self.rect = self.image.get_rect(center=center)

    def update(self, dx, dy):
        self.rect.move_ip(dx, dy)

    def draw(self, surface):
        surface.blit(self.image, self.rect)
```

</div>

המתודה `draw()` שכתבנו היא מתודה שלנו; היא מציירת את הספרייט באמצעות `blit()`. ירושה מ־`Sprite` אינה מציירת ואינה מזיזה את האובייקט אוטומטית. על התוכנית לקרוא לפעולות האלה, ישירות או בעזרת קבוצה שנכיר בהמשך.

### שימוש בספרייט יחיד

הוסיפו את הגדרת המחלקה אחרי הייבוא, ולפני שאר התוכנית. התמונה היא אותה [תמונת כוכב](../assets/pygame/star.png) מפרק התמונות, שנשמרת ב־`img/star.png`.

<div class="code-panel" dir="ltr">

```python
import pygame

# Paste the MovingImage class here.

pygame.init()
screen = pygame.display.set_mode((640, 400))
clock = pygame.time.Clock()
image = pygame.image.load("img/star.png").convert_alpha()
image = pygame.transform.scale(image, (60, 60))
star = MovingImage(image, (320, 200))
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    if not running:
        break

    star.update(1, 0)
    screen.fill((17, 43, 65))
    star.draw(screen)
    pygame.display.update()
    clock.tick(60)

pygame.quit()
```

</div>

הספרייט ינוע ימינה, ובסופו של דבר יצא מהחלון. היציאה אינה מסירה אותו מהזיכרון ואינה משנה את מיקומו אוטומטית לצד השני.

### שליטה במקלדת

כדי לשלוט במיקום במקום התנועה האוטומטית, מחליפים את `star.update(1, 0)` בקטע הבא:

<div class="code-panel" dir="ltr">

```python
keys = pygame.key.get_pressed()
dx = 3 * (keys[pygame.K_RIGHT] - keys[pygame.K_LEFT])
dy = 3 * (keys[pygame.K_DOWN] - keys[pygame.K_UP])
star.update(dx, dy)
```

</div>

כל מצב מקש הוא אמת או שקר; בחשבון הם מתנהגים כמו 1 או 0. שני מקשים מנוגדים מבטלים זה את זה. אפשר לכתוב אותו חישוב גם באמצעות תנאי `if` נפרדים.

### כמה עצמים, התנהגויות שונות

אפשר ליצור מופע שני של אותה מחלקה. לפני הלולאה נכתוב `other = MovingImage(image, (100, 100))`. בכל פריים נקרא ל־`other.update(1, 1)` ול־`other.draw(screen)`, נוסף לעדכון ולציור של `star`. כך עצם אחד נשלט במקלדת והאחר נע אוטומטית.

### מה פירוש kill?

הפעולה `star.kill()` מסירה את הספרייט מכל קבוצות הספרייטים שאליהן הוא שייך. היא אינה מוחקת את האובייקט מפייתון ואינה מוחקת פיקסלים שכבר צוירו על המסך. אם ממשיכים לקרוא ישירות ל־`star.draw(screen)`, עדיין אפשר לצייר אותו. בפרק הקבוצות נראה כיצד ההסרה מפסיקה את ציורו במסגרת הקבוצה, לאחר ניקוי הרקע.

**קוד להורדה:** [הדוגמה המלאה](../assets/pygame/examples/11-demo.py). בדוגמאות המשתמשות בתמונה, שמרו את [הכוכב](../assets/pygame/star.png) בתוך `img/star.png` לצד הקובץ והריצו מתוך התיקייה שלו.
