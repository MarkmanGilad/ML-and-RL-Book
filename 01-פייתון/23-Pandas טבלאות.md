## א.23 — Pandas — סדרות וטבלאות

כשנתונים מתארים אנשים, מכוניות או תוצאות ניסוי, נוח לסדר אותם בטבלה: כל שורה היא רשומה וכל עמודה היא פרט מסוים. Pandas היא ספרייה לטעינה, לבחירה ולעיבוד של נתונים כאלה, בלי לכתוב לולאה נפרדת לכל עמודה.

נכיר שני מבנים: `Series` היא סדרת ערכים עם תוויות, ו־`DataFrame` היא טבלה של עמודות עם אינדקס לשורות. לעמודות שונות יכולים להיות טיפוסים שונים. אינדקס ב־Pandas אינו חייב להיות מספר סידורי או להיות ייחודי.

**[מחברות האוניברסיטה הפתוחה — 13 קבצים וחבילות](https://drive.google.com/drive/folders/1yLN-J12Mq3KZ0i6XJwpaA3XMC6xoh4GJ?usp=sharing)**


### יוצרים Series

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
import pandas as pd
s = pd.Series({"a": 100, "b": 200, "c": 300})
print(s.loc["b"])
print(s.iloc[1])
print(s.mean())
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
200
200
200.0
```

</div>

`loc` בוחרת לפי **תווית**; `iloc` לפי **מיקום** שמתחיל באפס. כאן שתי הבחירות מגיעות לאותו ערך, אבל מסיבות שונות. אפשר ליצור סדרה גם מרשימה, ואז מתקבל אינדקס מספרי כברירת מחדל.

### יוצרים DataFrame ממילון

המפתחות הופכים לשמות עמודות, וכל רשימה מכילה את ערכי העמודה. רשימות אלה צריכות להיות באותו אורך.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
data = {
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [25, 30, 35],
    "City": ["New York", "Los Angeles", "Chicago"]
}
people = pd.DataFrame(data)
print(people["Age"].tolist())
print(people.shape)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[25, 30, 35]
(3, 3)
```

</div>

`shape` מחזירה מספר שורות ומספר עמודות. בחירה בשם עמודה יחיד מחזירה `Series`; בחירה ברשימת שמות, כגון `people[["Name", "Age"]]`, מחזירה טבלה.

### שורות ותוויות

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
named = people.set_index("Name")
print(named.loc["Bob", "Age"])
print(people.iloc[0]["Name"])
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
30
Alice
```

</div>

`set_index` בוחרת עמודה כאינדקס. `reset_index` מחזירה את התוויות לעמודה ואת האינדקס למספרים; `drop=True` מוותרת על שמירת האינדקס הישן. חיתוך מיקומים ב־`iloc` אינו כולל את הגבול האחרון; חיתוך תוויות ב־`loc` כולל בדרך כלל גם את תווית הסיום.

### סינון ועדכון

השוואה של עמודה למספר יוצרת מסכה בוליאנית. משתמשים בה לבחירת השורות שבהן התנאי מתקיים:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
selected = people[people["Age"] >= 30]
print(selected["Name"].tolist())
people["NextAge"] = people["Age"] + 1
print(people["NextAge"].tolist())
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
['Bob', 'Charlie']
[26, 31, 36]
```

</div>

לחיבור תנאים על עמודות משתמשים ב־`&` או ב־`|`, עם סוגריים סביב כל תנאי. `and` ו־`or` אינן מחברות מסכות שלמות. עדכון ממוקד נכתב בפעולת `loc` אחת:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
people.loc[people["Age"] >= 30, "City"] = "Updated"
ordered = people.sort_values("Age", ascending=False)
print(ordered["Name"].tolist())
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
['Charlie', 'Bob', 'Alice']
```

</div>

`drop` מסירה שורה לפי תווית, או עמודות באמצעות `columns`. פעולות רבות מחזירות טבלה חדשה; שומרים אותה בהשמה אם רוצים להמשיך איתה.

### טעינה ושמירה של CSV

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
path = "/content/people.csv"
people.to_csv(path, index=False)
loaded = pd.read_csv(path)
print(loaded.shape)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
(3, 4)
```

</div>

כעת יש ארבע עמודות, כולל `NextAge`. `index=False` מונעת הוספת אינדקס השורות כעמודה בקובץ. לאחר טעינה, `head()` ו־`tail()` מציגות שורות מתחילת הטבלה ומסופה; `info()` מציגה טיפוסים ומספר ערכים שאינם חסרים, ו־`describe()` מסכמת עמודות מספריות. מריצים `info()` ישירות: היא כבר מדפיסה את המידע.
