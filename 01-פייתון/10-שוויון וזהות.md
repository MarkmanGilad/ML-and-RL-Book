## א.10 — שוויון, זהות והעתקה

שני משתנים יכולים להפנות לאותה רשימה, או לשתי רשימות שונות עם אותם ערכים. ההבדל מתגלה כשמשנים איבר: אם זו אותה רשימה, השינוי נראה דרך שני השמות. בפרק נלמד לזהות את המצב וליצור העתק כשצריך.

**[מחברות האוניברסיטה הפתוחה — 6-שוויון וזהות](https://drive.google.com/drive/folders/1yLN-J12Mq3KZ0i6XJwpaA3XMC6xoh4GJ?usp=sharing)**


### השמה אינה העתקה

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
a = [1, 2]
b = a
b[1] = 3
print(a)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[1, 3]
```

</div>

`b = a` קושרת שם נוסף לאותה רשימה. לעומת זאת, `b = [7, 8]` הייתה קושרת את `b` לרשימה אחרת, בלי לשנות את `a`.

### שוויון לעומת זהות

`==` משווה תוכן לפי כללי הטיפוס. `is` בודקת אם שני השמות מפנים לאותו אובייקט.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b)
print(a is b)
print(a is c)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
True
False
True
```

</div>

השוואת מספרים ומחרוזות נעשית ב־`==`. מול `None` משתמשים ב־`is None`.

### העתקה רדודה

`copy()` יוצרת רשימה חיצונית חדשה. אם הרשימה מכילה רשימות, איבריה הפנימיים עדיין משותפים:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
rows = [[1, 2], [3, 4]]
other = rows.copy()
rows[0][1] = 5
print(other)
print(rows is other)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[[1, 5], [3, 4]]
False
```

</div>

### העתקה עמוקה

מודול הוא אוסף קוד שאפשר לייבא. המודול המובנה `copy` מספק `deepcopy`, שמעתיקה בדוגמה גם את הרשימות הפנימיות:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
import copy
rows = [[1, 2], [3, 4]]
other = copy.deepcopy(rows)
rows[0][1] = 5
print(rows)
print(other)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[[1, 5], [3, 4]]
[[1, 2], [3, 4]]
```

</div>

### העברת רשימה לפונקציה

הפרמטר מפנה לאובייקט שהועבר. שינוי איבריו נראה אצל הקורא; השמה של רשימה אחרת לפרמטר משנה רק את הקישור המקומי.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
def add_item(items):
    items.append(3)

def replace_items(items):
    items = [9]

numbers = [1, 2]
add_item(numbers)
replace_items(numbers)
print(numbers)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[1, 2, 3]
```

</div>

זו הסיבה להימנע מרשימה משתנה כברירת מחדל לפונקציה: אובייקט ברירת המחדל משותף לקריאות. כשנדרש אוסף חדש לכל קריאה, משתמשים ב־`None` ויוצרים את הרשימה בתוך הגוף.
