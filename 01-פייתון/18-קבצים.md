## א.18 — קבצים — קריאה וכתיבה

משתנים נשמרים בזיכרון של התוכנית. כדי להשתמש במידע גם אחרי סיום ההרצה, שומרים אותו בקובץ: למשל רשימת שמות, תוצאות משחק או טבלה. התוכנית פותחת קובץ, קוראת או כותבת בו, וסוגרת אותו בסיום.

קובץ טקסט מכיל תווים לפי קידוד, כגון UTF-8. תמונה וקובצי נתונים אחרים נקראים לעיתים כבייטים במצב בינארי. נתחיל בטקסט.

**[מחברות האוניברסיטה הפתוחה — 13 קבצים וחבילות](https://drive.google.com/drive/folders/1yLN-J12Mq3KZ0i6XJwpaA3XMC6xoh4GJ?usp=sharing)**


### קבצים ב־Colab

כדי שהמחברת תוכל לקרוא קובץ, הוא צריך להיות זמין בסביבת הריצה שלה. פתחו את חלונית הקבצים שבצד המחברת והעלו את קובץ הליווי. נתיב כגון `/content/hello_world.txt` מציין קובץ במחשב שבו רצה המחברת, ולא במחשב האישי. קבצים בסביבת הריצה זמניים; שמרו תוצאה שרוצים לשמור באמצעות הורדה או ב־Drive.

### כתיבה וקריאה באמצעות with

כדי לשמור טקסט ולקבל אותו בחזרה, נפתח קובץ לכתיבה ולאחר מכן לקריאה. `open` מקבלת נתיב, מצב פתיחה וקידוד. `with` דואגת לסגירת הקובץ ביציאה מהבלוק, גם אם נוצרה בתוכו חריגה.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
path = "/content/hello_world.txt"
with open(path, "w", encoding="utf-8") as file:
    file.write("Hello, World!\n")

with open(path, "r", encoding="utf-8") as file:
    text = file.read()
print(text, end="")
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
Hello, World!
```

</div>

מצב `r` קורא קובץ קיים. **מצב `w` מוחק תוכן קודם**, או יוצר קובץ חדש. `a` מוסיפה בסוף ויוצרת קובץ אם חסר; `x` יוצרת קובץ חדש ונכשלת אם הוא כבר קיים.

### הוספה וקריאה שורה אחר שורה

אפשר להוסיף טקסט בסוף קובץ בלי למחוק את תוכנו הקודם. נוסיף שורה לקובץ שיצרנו, ואז נקרא את השורות לפי סדרן.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
with open(path, "a", encoding="utf-8") as file:
    file.write("Second line\n")

with open(path, "r", encoding="utf-8") as file:
    for line in file:
        print(line, end="")
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
Hello, World!
Second line
```

</div>

`read()` קוראת את יתר התוכן; `readline()` קוראת שורה אחת; `readlines()` מחזירה רשימת שורות. שורה שנקראה כוללת בדרך כלל את `\n`, ולכן `end=""` מונעת ירידת שורה כפולה בהדפסה. סריקה שורה אחר שורה חוסכת טעינת כל הקובץ למחרוזת אחת.

### כתיבת כמה שורות

כשכמה שורות כבר שמורות ברשימה, אפשר לכתוב אותן יחד לקובץ. `writelines` כותבת רצף מחרוזות, בלי להוסיף מפרידים מעצמה:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
lines = ["First line\n", "Second line\n"]
with open(path, "w", encoding="utf-8") as file:
    file.writelines(lines)
```

</div>

### מיקום הקריאה והמצב הבינארי

הקריאה מתקדמת בקובץ. אחרי `read()` עד הסוף, קריאה נוספת מחזירה מחרוזת ריקה. `seek(0)` חוזרת להתחלה; `tell()` מחזירה סימון של המיקום הנוכחי. בטקסט רב־בתי אין להתייחס לסימון הזה כאל מספר תווים פשוט.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
with open(path, "r", encoding="utf-8") as file:
    first = file.read()
    print(file.read() == "")
    file.seek(0)
    print(file.readline(), end="")
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
True
First line
```

</div>

לקריאת בייטים משתמשים ב־`rb`, ולכתיבתם ב־`wb`, ללא `encoding`. הסימן `+` מוסיף אפשרות קריאה וכתיבה יחד; למשל `r+` דורש קובץ קיים ו־`w+` מתחיל מתוכן ריק.

### קובץ חסר

ניסיון לקרוא קובץ שאינו קיים יוצר חריגה. אפשר לטפל בה באמצעות `FileNotFoundError` ולהציג הודעה מתאימה:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
try:
    with open("/content/missing.txt", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("File not found")
```

</div>

לאחר הטיפול בחריגה לא מניחים ש־`text` קיבל ערך. תקלה בהרשאה יכולה ליצור `PermissionError`, ותוכן שאינו מתאים לקידוד יכול ליצור שגיאת פענוח.

### CSV — טבלה בקובץ טקסט

בקובץ CSV כל רשומה מתארת שורה, והשדות מופרדים בדרך כלל בפסיקים. לדוגמה, הכותרת יכולה להיות `Name,Age` ואחריה הרשומה `Dana,17`. ערך עשוי להכיל פסיק בתוך מירכאות, ולכן `split(",")` לבדה אינה קוראת CSV כללי כראוי. בפרק Pandas נקרא טבלה באמצעות `read_csv` ונשמור באמצעות `to_csv`.
