## א.6 — לולאות

לולאה חוזרת על הוראות בלי לשכפל אותן בקוד. למשל, אפשר להציג ספירה לאחור או לבדוק את התווים במילה. `while` חוזרת כל עוד תנאי מתקיים; `for` עוברת על רצף ערכים.

**[מחברות האוניברסיטה הפתוחה — 3-לולאות](https://drive.google.com/drive/folders/1yLN-J12Mq3KZ0i6XJwpaA3XMC6xoh4GJ?usp=sharing)**


### לולאת while


התנאי נבדק לפני כל איטרציה. **אין צורך בסוגריים סביב התנאי; מסיימים את שורת הכותרת בנקודתיים ומזיחים את גוף הלולאה.**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
count = 3

while count > 0:
    print(count)
    count -= 1

print("Go!")
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
3
2
1
Go!
```

</div>

`break` מסיימת את הלולאה מיד. `continue` מדלגת על המשך האיטרציה הנוכחית.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
i = 0

while i < 6:
    i += 1
    if i == 3:
        continue
    print(i)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
1
2
4
5
6
```

</div>

אפשר להוסיף `else` ללולאת `while`: היא תבוצע בסיום רגיל, כשהתנאי נעשה שקרי, אך לא ביציאה באמצעות `break`. ה־`else` מיושרת עם `while`, ולא עם ה־`if` שבתוכה.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
attempts = 0

while attempts < 3:
    attempts += 1
    if attempts == 2:
        print("Found")
        break
else:
    print("Not found")
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
Found
```

</div>

בלוק ה־`else` לא יבוצע, משום שהלולאה הסתיימה באמצעות `break`. [פירוט על לולאות ו־else](https://docs.python.org/3/tutorial/controlflow.html).

### לולאת for ו־range

`for` עוברת על איברים באמצעות `in`. **שורת הכותרת מסתיימת בנקודתיים, וגוף הלולאה מוזח:**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
for letter in "Python":
    print(letter)
```

</div>

כאן כל איטרציה מקבלת את התו הבא במחרוזת; בהמשך נסרוק באותה צורה רשימות.

למספר חזרות ידוע משתמשים ב־`range`:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
for i in range(4):
    print(i)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
0
1
2
3
```

</div>

ערך הסיום אינו נכלל. אפשר לציין התחלה, סיום וצעד:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
for i in range(1, 8, 2):
    print(i)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; display: block !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
1
3
5
7
```

</div>

`range` מייצגת טווח מספרים; אין צורך ליצור עבורו רשימה בזיכרון.

<!-- editorlm-source-ref: [sources/Python/converted/1.Python_Basic/notebook.md#L232-L300] -->
### צובר ולולאות מקוננות

צובר הוא משתנה שמרכז תוצאה לאורך הלולאה. מאתחלים אותו לפני הלולאה ומעדכנים בכל חזרה:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
total = 0
for number in range(1, 5):
    total += number
print(total)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
10
```

</div>

לולאה פנימית מתבצעת מחדש לכל איטרציה של החיצונית. כאן מדפיסים שתי שורות, בכל אחת שלושה מספרים:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
for row in range(2):
    for column in range(3):
        print(column, end=" ")
    print()
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 50% !important; max-width: 50% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
0 1 2
0 1 2
```

</div>

ה־`print()` האחרון נמצא בתוך הלולאה החיצונית אך מחוץ לפנימית, ולכן יורד שורה פעם אחת לכל שורה. בלולאת `while` ודאו שיש דרך להגיע לסיום; `continue` אינה מבצעת עבורכם את עדכון משתנה הבקרה.
