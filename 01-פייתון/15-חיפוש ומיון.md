## א.15 — חיפוש, מיון ויעילות

אלגוריתם הוא סדר צעדים לפתרון בעיה. שתי תוכניות יכולות למצוא אותו מספר, אך לבצע כמות שונה מאוד של עבודה. נשתמש בחיפוש ובמיון כדי להבין כיצד גודל הרשימה משפיע על מספר הפעולות.

**[מחברות האוניברסיטה הפתוחה — 10-אלגורתמים; 6-שוויון וזהות](https://drive.google.com/drive/folders/1yLN-J12Mq3KZ0i6XJwpaA3XMC6xoh4GJ?usp=sharing)**


### חיפוש לינארי

עוברים על האיברים עד שמוצאים את הערך. הפונקציה מחזירה את האינדקס הראשון שלו, או `-1` אם אינו מופיע:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
def find(numbers, value):
    for i in range(len(numbers)):
        if numbers[i] == value:
            return i
    return -1

print(find([3, 6, 1, 9, 10, 4], 10))
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
4
```

</div>

ברשימה באורך `n`, במקרה הגרוע נבדוק `n` איברים. מסמנים קצב גידול כזה ב־`O(n)`; הסימון מתאר כיצד העבודה גדלה, לא זמן בשניות.

### חיפוש בינארי

**הרשימה חייבת להיות ממוינת.** בודקים את האמצע: אם הוא קטן מהערך המבוקש ממשיכים בחצי הימני; אחרת בחצי השמאלי. בכל צעד מוותרים על כמחצית הטווח.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
def binary_find(numbers, value):
    left = 0
    right = len(numbers) - 1
    while left <= right:
        middle = (left + right) // 2
        if numbers[middle] == value:
            return middle
        if numbers[middle] < value:
            left = middle + 1
        else:
            right = middle - 1
    return -1

print(binary_find([3, 5, 7, 9, 12], 9))
print(binary_find([], 9))
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
3
-1
```

</div>

הגבול הימני הוא האינדקס האחרון, `len(numbers) - 1`. מספר הצעדים גדל כמו `O(log n)`. מיון חדש של הרשימה לפני כל חיפוש הוא עבודה נוספת; החיסכון מתאים במיוחד לנתונים שכבר ממוינים או לחיפושים חוזרים.

### מיון לפי מפתח

בדרך כלל נשתמש ב־`sort` או ב־`sorted` המובנות. פונקציית `key` מקבלת איבר ומחזירה את הערך שלפיו ימוין. למשל, מיון זוגות לפי סכום שני המספרים:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
def pair_sum(pair):
    return pair[0] + pair[1]

pairs = [(3, 4), (1, 2), (3, 3), (0, 5), (5, 0)]
print(sorted(pairs, key=pair_sum))
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[(1, 2), (0, 5), (5, 0), (3, 3), (3, 4)]
```

</div>

`key` אינה מקבלת שני איברים להשוואה, אלא איבר אחד. כששני מפתחות שווים, המיון שומר על הסדר המקורי שלהם. אפשר לכתוב את פונקציית הביטוי הקצרה כך: `key=lambda pair: pair[0] + pair[1]`.

### איך מיון עובד?

מחברת האלגוריתמים מציגה כמה שיטות: **מיון בחירה** בוחר בכל פעם את האיבר הקטן שנותר; **מיון בועות** מחליף שכנים שאינם בסדר; **מיון הכנסה** מכניס כל איבר למקומו בחלק שכבר מוין. במקרים הגרועים, שלוש השיטות עשויות לבצע סדר גודל של `n²` פעולות.

**מיון מיזוג** מחלק לשני חצאים, ממיין אותם וממזג. המיזוג עצמו מתקדם בכל פעם בחצי שממנו נלקח האיבר הקטן. כמות העבודה הכוללת היא `O(n log n)`. **מיון מנייה** מתאים לערכים בטווח שלמים מוגבל: סופרים הופעות ולא משווים כל זוג. גודל טווח הערכים חשוב, ולכן הוא אינו תחליף כללי לכל מיון.

אין צורך לממש מיון מחדש בכל תוכנית. ההיכרות עם השיטות עוזרת להבין את העלות של הפתרון שבחרנו.

### גיבוב — מדוע מפתח עוזר בחיפוש?

במילון ובקבוצה משתמשים במנגנון גיבוב: מחשבים מתוך המפתח מספר שמכוון לאזור שבו נשמר המידע, במקום לסרוק בהכרח את כל האוסף. מפתחות שונים עשויים להגיע לאותו אזור; המימוש צריך לטפל בהתנגשות ולבדוק גם את המפתח עצמו.

גישה לפי מפתח במילון ובדיקת חברות בקבוצה הן בדרך כלל בעלות זמן ממוצע `O(1)`, ולא הבטחה שכל פעולה בכל מצב תהיה קבועה. חיפוש לפי **ערך** במילון עדיין עשוי לדרוש סריקה. האינדקסים הפנימיים אינם המפתחות שבממשק: בספר הטלפונים פונים בשם, גם אם מאחורי הקלעים משתמשים בטבלה.

### הרחבה: פונקציות שפועלות על רצפים

איטרטור מספק את האיבר הבא בכל פעם שמבקשים אותו. אפשר לסרוק אותו ב־`for`, או לקרוא ל־`next`. בניגוד לרשימה, אין להניח שאפשר לחזור ולקרוא את כל תוצאותיו לאחר שכבר נצרכו.

`map` מפעילה פונקציה על כל איבר ומספקת את התוצאות. היא אינה משנה את רשימת המקור. בדוגמה `next` כבר צרכה את התוצאה הראשונה, ולכן היא אינה מופיעה ברשימה שאחריה:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
def double(value):
    return 2 * value

numbers = [3, -3, 2, 0, 10, -11]
results = map(double, numbers)
print(next(results))
print(list(results))
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
6
[-6, 4, 0, 20, -22]
```

</div>

`filter` מספקת רק איברים שעוברים בדיקה. `zip` מצמידה איברים במיקומים תואמים מכמה רצפים. שתיהן מחזירות איטרטורים; כאן נהפוך אותם לרשימות לצורך הצגה:

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
positive = filter(lambda value: value > 0, numbers)
print(list(positive))
print(list(zip([1, 2, 3], [4, 5, 6])))
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[3, 2, 10]
[(1, 4), (2, 5), (3, 6)]
```

</div>

`lambda value: value > 0` היא פונקציה קצרה שמחזירה את תוצאת הביטוי. בברירת המחדל, `zip` נעצרת עם סיום הרצף הקצר ביותר.

### הרחבה: יצירת רשימה בביטוי

לאחר שמכירים לולאה וסינון, אפשר לקצר יצירה של רשימה באמצעות list comprehension. קוראים את הביטוי כך: עבור כל ערך, אם הוא חיובי, הכנס לרשימה את הערך כפול שניים.

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```python
numbers = [3, -3, 2, 0, 10, -11]
positive_doubles = [2 * value for value in numbers if value > 0]
print(positive_doubles)
```

</div>

**פלט**

<div class="code-panel" dir="ltr" style="box-sizing: border-box !important; width: 75% !important; max-width: 75% !important; margin: 18px auto !important; direction: ltr !important; text-align: left !important;">

```text
[6, 4, 20]
```

</div>

כאשר הביטוי נעשה קשה לקריאה, לולאה רגילה עם `append` תהיה ברורה יותר. שתי הדרכים יוצרות כאן רשימה חדשה.
