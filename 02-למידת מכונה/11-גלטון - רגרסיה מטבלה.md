### דוגמה נוספת מהמחברות: גובה ילדים — Galton

כאן מנבאים גובה מתוך חמש תכונות: גובה האב, גובה האם, מספר הילדים במשפחה, המספר הסידורי של הילד והמין. קובץ CSV הוא טבלה; pandas קוראת אותה ל־DataFrame, שממנו נבחר עמודות לפי שם.

<div class="code-panel" dir="ltr">

```python
import pandas as pd

url = (
    "https://raw.githubusercontent.com/"
    "MarkmanGilad/Galton_Heights/"
    "refs/heads/main/Data/galton.csv"
)
df = pd.read_csv(url)
df["gender"] = (df["gender"] == "female").astype(int)
columns = ["father", "mother", "children",
           "childNum", "gender"]
x_raw = torch.tensor(
    df[columns].to_numpy(), dtype=torch.float32
)
y_raw = torch.tensor(
    df[["childHeight"]].to_numpy(),
    dtype=torch.float32
)
x_raw *= torch.tensor([2.54, 2.54, 1, 1, 1])
y_raw *= 2.54
```

</div>

אין משתמשים במספר המשפחה כתכונת חיזוי. רק עמודות הגובה מומרות מאינצ׳ים לסנטימטרים. בדוגמה זו ננרמל **גם את היעד** ונחזיר את התחזית לסנטימטרים בסוף.

<div class="code-panel" dir="ltr">

```python
minimum = x_raw.min(dim=0).values
scale = x_raw.max(dim=0).values - minimum
x = (x_raw - minimum) / scale
y_min = y_raw.min()
y_scale = y_raw.max() - y_min
y = (y_raw - y_min) / y_scale
model = nn.Linear(5, 1)
optimizer = torch.optim.SGD(
    model.parameters(), lr=0.01
)
for epoch in range(2000):
    optimizer.zero_grad()
    loss = nn.functional.mse_loss(model(x), y)
    loss.backward()
    optimizer.step()

new_raw = torch.tensor([
    [184., 161., 4., 1., 0.],
    [184., 161., 4., 3., 1.],
    [179., 170., 2., 1., 0.],
    [175., 177., 3., 3., 1.]
])
with torch.no_grad():
    normalized = model((new_raw-minimum)/scale)
    height_cm = normalized * y_scale + y_min
print(height_cm)
```

### הכנת טבלה היא חלק מהמודל

בנתוני גלטון יש גם מזהה משפחה. מזהה אינו מידה כמותית: משפחה שמספרה 100 אינה ״פי שניים״ ממשפחה 50. לכן בוחרים מראש את חמש עמודות הקלט לפי שמותיהן. אין צורך להפוך כל עמודת טקסט למספר רק כדי שיהיה אפשר להמיר את כל הטבלה בבת אחת.

הכפלה ב־2.54 מתאימה רק לגבהים שניתנו באינצ׳ים. מספר הילדים, סדר הילד ותווית המין נשארים ללא שינוי. בקלט תחזית חדש שכבר נכתב בסנטימטרים לא מבצעים את ההכפלה שוב. מומלץ לכתוב לצד כל עמודה את היחידה ואת הקידוד לפני האימון.

### שגיאה ביחידות שקל לפרש

אחרי אימון על גובה מנורמל, נחשב את התחזיות מחדש במשקלים הסופיים ונחזיר לסנטימטרים. ממוצע שגיאה מוחלטת — MAE — נמדד בסנטימטרים, בעוד MSE נמדד בסנטימטרים בריבוע.

<div class="code-panel" dir="ltr">

```python
with torch.no_grad():
    predicted_cm = model(x) * y_scale + y_min
    error_cm = predicted_cm - y_raw
    mae_cm = error_cm.abs().mean()
    mse_cm2 = error_cm.square().mean()
print("MAE (cm):", mae_cm.item())
print("MSE (cm^2):", mse_cm2.item())
```

</div>

הקוד כאן עדיין מודד את דוגמאות האימון. אם נרצה לבדוק הכללה למשפחות חדשות, כדאי להפריד לפי משפחה, כדי שילדים מאותה משפחה לא יופיעו משני צדי החלוקה. לאחר ההפרדה מחשבים פרמטרי נרמול מן האימון בלבד. זו הרחבה של עקרון מניעת דליפת מידע: קרבה בין דוגמאות יכולה ליצור יתרון מלאכותי גם בלי להעתיק תווית ישירות.

בגרף ״אמיתי מול חזוי״, נקודה על האלכסון מציינת התאמה מושלמת; מעליו תחזית גבוהה מהאמת ומתחתיו נמוכה. מבט על הפיזור מלמד יותר מהסתכלות על מספר הפסד בודד. תחזיות לילדים נוספים באותה משפחה מדגימות שימוש במודל, אך אינן מדידות חדשות של גובהם.
