## ב.17 רשת במחלקה — סיווג עשר ספרות


**[השיעור וההרצאות באתר של גלעד מרקמן](https://webprogramming.azurewebsites.net/Pages/PyTorch/ANN_Class_Softmax.aspx)**

[פתיחת מחברת Colab 1](https://colab.research.google.com/drive/1jmHPIUBkP52cEfqCHmeMJVnestyXDJFO?usp=sharing)

**חומרי הליווי:** [9. רשת נורונים באמצעות מחלקה](../../../sources/ML/9.%20%D7%A8%D7%A9%D7%AA%20%D7%A0%D7%95%D7%A8%D7%95%D7%A0%D7%99%D7%9D%20%D7%91%D7%90%D7%9E%D7%A6%D7%A2%D7%95%D7%AA%20%D7%9E%D7%97%D7%9C%D7%A7%D7%94.pptx) · [9_ANN_Class](../../../sources/ML/converted/9_ANN_Class/notebook.md) · [Classified_Iris_FashionMNIST](../../../sources/ML/converted/Classified_Iris_FashionMNIST/notebook.md) · [Pima_Diabetes](../../../sources/ML/converted/Pima_Diabetes/notebook.md)


### המשימה: איזו ספרה מופיעה בתמונה?

כעת נרצה לבחור בין הספרות 0–9. הקלט נשאר 784 פיקסלים, אך הפלט יכיל **עשרה ציונים — ציון לכל ספרה**. התווית האמיתית היא מספר שלם מ־0 עד 9.

נשתמש שוב בטעינת MNIST וב־DataLoader שהוגדרו בפרק ב.13. במחברת חדשה יש להריץ קודם את תאי הייבוא, בחירת device, טעינת הנתונים ויצירת הטוענים משם. אין להשתמש כאן בהמרת התוויות ל־7 או לא 7.

### הגדרת מחלקת המודל

מחלקת רשת יורשת מ־**nn.Module**. בפונקציה __init__ מגדירים את השכבות; בפונקציה **forward** מגדירים כיצד הנתונים עוברים ביניהן. הקריאה super().__init__ מאתחלת את מחלקת הבסיס.

<div class="code-panel" dir="ltr">

```python
class DigitNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.first = nn.Linear(784, 200)
        self.second = nn.Linear(200, 100)
        self.output = nn.Linear(100, 10)

    def forward(self, x):
        x = x.reshape(-1, 784)
        x = torch.relu(self.first(x))
        x = torch.relu(self.second(x))
        return self.output(x)

model = DigitNet().to(device)
```

</div>

השכבות נשמרות כשדות של המודל, ולכן PyTorch יכולה למצוא את הפרמטרים שלהן. מפעילים את הרשת באמצעות **model(x)**; אין צורך לקרוא ישירות ל־forward.

### ציונים, הסתברויות ותוויות

עשרת המספרים שהרשת מחזירה הם **logits** — ציונים שאינם חייבים להיות בין 0 ל־1. **argmax** בוחרת את מיקום הציון הגדול ביותר, שהוא מספר הספרה החזויה.

אם רוצים להציג הסתברויות, אפשר להפעיל Softmax לאורך ציר הקטגוריות:

<div class="code-panel" dir="ltr">

```python
images, labels = next(iter(test_loader))
with torch.no_grad():
    logits = model(images.to(device))
    probabilities = torch.softmax(logits, dim=1)
    predicted = logits.argmax(dim=1)
```

</div>

לפני אימון, הציונים האלה נובעים ממשקלים התחלתיים ואינם תחזיות שימושיות.

**One-hot** הוא ייצוג שבו לכל קטגוריה תא נפרד: עבור הספרה 2 התא השלישי יהיה 1 והשאר 0. בדוגמה שלנו אין צורך להמיר אליו את התוויות.

### דוגמה מספרית של Softmax

נניח שהרשת מחזירה שלושה ציונים [2,1,0]. Softmax מחשבת `exp(zᵢ)/Σexp(zⱼ)` ומחזירה בקירוב [0.6652,0.2447,0.0900]. הסכום 1, והמיקום בעל הציון הגדול ביותר נשאר המיקום בעל ההסתברות הגדולה ביותר. לכן לצורך בחירת קטגוריה אפשר להפעיל argmax ישירות על הציונים.

<div class="code-panel" dir="ltr">

```python
scores = torch.tensor([[2., 1., 0.]])
print(torch.softmax(scores, dim=1))
print(scores.argmax(dim=1))
```

</div>

**פלט**

<div class="code-panel" dir="ltr">

```text
tensor([[0.6652, 0.2447, 0.0900]])
tensor([0])
```

</div>

אם הקטגוריה הנכונה היא 0, ההפסד הוא בערך ‎−ln(0.6652)=0.4076. אם היא 2, ההפסד כ־2.4076. אותו וקטור תחזית מקבל הפסד שונה בהתאם לתשובה הנכונה. ב־CrossEntropyLoss מעבירים את scores ואת אינדקס היעד; הספרייה מבצעת את החישוב בצורה משולבת.

### מחלקת מודל היא תיאור חישוב הניתן לשימוש חוזר

כל יצירה של `DigitNet()` יוצרת מופע חדש עם פרמטרים משלו. קריאות חוזרות ל־`model(images)` משתמשות באותם פרמטרים; לכן אין ליצור מחדש את השכבות בתוך forward. אילו היינו יוצרים שם Linear חדשה בכל קריאה, היינו מחליפים את המשקלים במקום ללמוד אותם לאורך האימון.

במודל שבפרק יש 157,000 פרמטרים בשכבה הראשונה, 20,100 בשנייה ו־1,010 באחרונה: 178,110 בסך הכול. `super().__init__()` ורישום השכבות בשדות `self` מאפשרים ל־PyTorch לאתר אותם לצורך אימון, העברה להתקן ושמירה.

### CrossEntropyLoss

**CrossEntropyLoss** מקבלת את הציונים הגולמיים בצורת `[batch,10]` ואת התוויות השלמות בצורת `[batch]`, בטיפוס long. היא משלבת את החישוב הדרוש לסיווג רב־קטגוריות; **אין להפעיל Softmax לפני ההפסד הזה**.

ההפסד הוא מספר המודד שגיאה, ולא וקטור one-hot או הספרה החזויה. [תיעוד CrossEntropyLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html).

<div class="code-panel" dir="ltr">

```python
loss_function = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(
    model.parameters(), lr=0.01
)
for epoch in range(5):
    model.train()
    total_loss = 0.
    for images, labels in train_loader:
        images = images.to(device)
        labels = labels.to(device)
        optimizer.zero_grad()
        logits = model(images)
        loss = loss_function(logits, labels)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * len(labels)
    print(epoch + 1, total_loss / len(train_data))
```

</div>

### בדיקת הדיוק

<div class="code-panel" dir="ltr">

```python
model.eval()
correct = 0
total = 0
with torch.no_grad():
    for images, labels in test_loader:
        logits = model(images.to(device))
        predicted = logits.argmax(dim=1).cpu()
        correct += (predicted == labels).sum().item()
        total += len(labels)
print(f"Accuracy: {100 * correct / total:.2f}%")
```

</div>
