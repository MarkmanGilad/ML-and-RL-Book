### נרמול הנתונים

נרמול משנה את סולם הערכים לפני הכנסתם למודל. שתי האפשרויות הבאות משתמשות במינימום ובמקסימום, או בממוצע ובסטיית התקן.

**Min–Max:** מחסרים את המינימום ומחלקים בטווח. ערכי האימון ממופים לתחום 0–1.

**Z-normalization:** מחסרים את הממוצע ומחלקים בסטיית התקן. שיטה זו אינה מגבילה את הערכים לתחום 0–1.

<div class="code-panel" dir="ltr">

```python
def Normalize_minMax(X, x_max, x_min):
    return (X - x_min) / (x_max - x_min)

def Normalize_z(X, mean, std):
    return (X - mean) / std
```

</div>
