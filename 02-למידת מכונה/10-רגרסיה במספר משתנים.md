### יותר מתכונה אחת

מחיר דירה עשוי להיות קשור גם לשטחה וגם לקומה שלה. לכל תכונה נותנים משקל נפרד. המודל הוא `ŷ = w₁*area + w₂*floor + b`.

כל **שורה** בטנסור תהיה דירה, וכל **עמודה** תהיה תכונה. הפלט עדיין מספר אחד לכל דירה.

לדוגמה, שני בתים יכולים להיות באותו שטח אך בקומות שונות. מודל המשתמש בשטח בלבד מוכרח לתת לשניהם אותה תחזית. הוספת הקומה מאפשרת לתחזיות להיות שונות. מבחינה גאומטרית עוברים מקו במישור למשטח מעל שני צירי קלט; מבחינת הקוד משתנה בעיקר מספר התכונות.

המשקל של כל תכונה מתאר את השפעתה במודל כאשר שאר התכונות מוחזקות קבועות. אין לפרש אותו אוטומטית כהוכחה לסיבה בעולם האמיתי. התאמה לנתונים היא קשר חזוי, והיא תלויה גם בתכונות שנבחרו ובאופן הכנתן.

### נתוני המחברת

<div class="code-panel" dir="ltr">

```python
import torch
from torch import nn
import matplotlib.pyplot as plt

area = torch.tensor([
    92, 105, 101, 109, 112,
    122, 131, 130, 141
], dtype=torch.float32).reshape(-1, 1)
floor = torch.tensor([
    3, 2, 9, 3, 7, 3, 6, 1, 5
], dtype=torch.float32).reshape(-1, 1)
y = torch.tensor([
    2.462, 2.661, 3.177, 2.972, 3.321,
    3.226, 3.648, 3.447, 3.848
]).reshape(-1, 1)
x_raw = torch.cat((area, floor), dim=1)
print(x_raw.shape)
```

### נרמול של כל עמודה בנפרד

טווחי השטח והקומה שונים. הפעולה min עם dim=0 עוברת לאורך השורות ומחזירה מינימום נפרד לכל עמודה; כך גם max.

<div class="code-panel" dir="ltr">

```python
minimum = x_raw.min(dim=0).values
maximum = x_raw.max(dim=0).values
scale = maximum - minimum
x = (x_raw - minimum) / scale
print(minimum)
print(maximum)
```

</div>

<div class="code-panel" dir="ltr">

### שכבה בעלת שני קלטים

המעבר מ־Linear(1,1) אל **Linear(2,1)** מוסיף משקל לקלט השני. פונקציית ההפסד ולולאת האימון נשארות כפי שהכרנו.

<div class="code-panel" dir="ltr">

```python
model = nn.Linear(2, 1)
loss_function = nn.MSELoss()
optimizer = torch.optim.SGD(
    model.parameters(), lr=0.1
)
losses = []
for epoch in range(1000):
    optimizer.zero_grad()
    prediction = model(x)
    loss = loss_function(prediction, y)
    loss.backward()
    optimizer.step()
    losses.append(loss.item())
```

</div>

### חיזוי לדירה חדשה

<div class="code-panel" dir="ltr">

```python
new_raw = torch.tensor([[110., 4.]])
new_x = (new_raw - minimum) / scale

```

סדר התכונות חייב להישאר **שטח ואז קומה**, כמו באימון. אין להחליף עמודות או לחשב נרמול חדש עבור הדירה היחידה.

### לחזור ממשקלים מנורמלים למשוואה ביחידות המקוריות

נסמן `x′ⱼ=(xⱼ−minⱼ)/scaleⱼ`. אם המודל למד `ŷ=Σw′ⱼx′ⱼ+b′`, אז המשקל ביחידות המקוריות הוא `wⱼ=w′ⱼ/scaleⱼ`, וההטיה היא `b=b′−Σw′ⱼminⱼ/scaleⱼ`. כך אפשר לקרוא משוואה של מחיר לפי מ״ר ולפי קומה, ולא לפי מספרים מנורמלים.

<div class="code-panel" dir="ltr">

```python
with torch.no_grad():
    original_weight = model.weight[0] / scale
    original_bias = model.bias[0] - (
        original_weight * minimum
    ).sum()
    first_way = model((new_raw-minimum)/scale)
    second_way = new_raw @ original_weight + original_bias
print(torch.allclose(first_way[:, 0], second_way))
```

</div>
