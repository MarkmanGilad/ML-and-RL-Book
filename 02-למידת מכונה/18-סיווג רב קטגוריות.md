### סיווג שלושת מיני Iris

במחברת Classified_Iris_FashionMNIST שומרים את שלוש התוויות המקוריות של Iris, ומחליפים את המודל הבינארי ברשת עם שלושה פלטים. כעת לא ממירים את התוויות להשוואה עם 1.

<div class="code-panel" dir="ltr">

```python
class IrisNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.first = nn.Linear(4, 64)
        self.second = nn.Linear(64, 128)
        self.output = nn.Linear(128, 3)

    def forward(self, x):
        x = torch.relu(self.first(x))
        x = torch.relu(self.second(x))
        return self.output(x)
```

</div>

הכנת הנתונים מתחילה ב־load_iris ובפיצול 80%/20% עם random_state=4. מנרמלים לפי האימון כמו בפרק ב.12; התוויות הפעם הן long חד־ממדיות. מאמנים את IrisNet עם CrossEntropyLoss ו־Adam בקצב 0.01 במשך 1,000 צעדים, ובוחרים את התווית באמצעות argmax.

### סיווג עשרת פריטי Fashion-MNIST

באותה מחברת עוברים גם משאלה בינארית על שמלה לבחירה בין עשר קטגוריות הלבוש. משתמשים בנתוני Fashion-MNIST שכבר הכרנו; התווית נשארת המספר המקורי.

<div class="code-panel" dir="ltr">

```python
class FashionNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.first = nn.Linear(784, 256)
        self.second = nn.Linear(256, 128)
        self.output = nn.Linear(128, 10)

    def forward(self, x):
        x = x.reshape(-1, 784)
        x = torch.relu(self.first(x))
        x = torch.relu(self.second(x))
        return self.output(x)
```

</div>

יוצרים טועני Fashion-MNIST באצוות של 50, מודל חדש ו־Adam בקצב 0.001. משתמשים בלולאת חמש תקופות האימון של DigitNet וב־CrossEntropyLoss. להצגת שם התחזית בוחרים `train_data.classes[prediction]`. הסתברות לתצוגה אפשר לחשב באמצעות Softmax, לאחר חישוב הציונים.

### לקרוא טעויות בסיווג רב־קטגוריות

ב־Iris הפלט הוא שלושה ציונים לכל פרח, וב־Fashion-MNIST עשרה לכל פריט. הצגת שם הקטגוריה ליד כל תמונה מאפשרת לזהות בלבול חוזר, למשל בין פריטים בעלי צללית דומה. הסתברות גבוהה אינה מוכיחה שהתשובה נכונה: בודקים אותה מול התווית, ולא מול מידת הביטחון של הרשת בלבד.

אפשר להשלים את הכנת Iris ואימונו כך, אחרי הגדרת IrisNet:

<div class="code-panel" dir="ltr">

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
xa, xb, ya, yb = train_test_split(
    iris.data, iris.target, test_size=0.2, random_state=4
)
xa = torch.tensor(xa, dtype=torch.float32)
xb = torch.tensor(xb, dtype=torch.float32)
ya = torch.tensor(ya, dtype=torch.long)
yb = torch.tensor(yb, dtype=torch.long)
minimum = xa.min(dim=0).values
scale = xa.max(dim=0).values - minimum
xa, xb = (xa-minimum)/scale, (xb-minimum)/scale
model = IrisNet()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
for step in range(1000):
    optimizer.zero_grad()
    loss = nn.functional.cross_entropy(model(xa), ya)
    loss.backward()
    optimizer.step()
with torch.no_grad():
    predicted = model(xb).argmax(dim=1)
print((predicted == yb).float().mean().item())
```

</div>

ל־Fashion-MNIST משתמשים באותה לולאה באצוות מהפרק הקודם, עם FashionNet. אין צורך להגדיר פונקציית הפסד שונה לכל שם קטגוריה: cross entropy משווה את הפלט לאינדקס המתאים.
