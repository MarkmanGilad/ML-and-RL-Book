## ב.14 מגבלות הקו הישר ורגרסיה באמצעות רשת


אופטימייזר יכול למצוא קו מתאים, אך אינו יכול להפוך קו לגל. כעת נשווה מודל לינארי לרשת שמסוגלת לתאר קשר עקום. נשתמש בנתונים מדומים כדי לדעת מהו הקשר ומהו הרעש, ונלמד גם כיצד מגישים דוגמאות דרך Dataset.

**[השיעור וההרצאות באתר של גלעד מרקמן](https://webprogramming.azurewebsites.net/Pages/PyTorch/ANN.aspx)**

**חומרי הליווי:** [8. רשת נורונים ANN](../../../sources/ML/8.%20%D7%A8%D7%A9%D7%AA%20%D7%A0%D7%95%D7%A8%D7%95%D7%A0%D7%99%D7%9D%20ANN.pptx) · [8_ANN_MNIST](../../../sources/ML/converted/8_ANN_MNIST/notebook.md) · [5.4_Linear_Regresion-Limitation](../../../sources/ML/converted/5.4_Linear_Regresion-Limitation/notebook.md) · [Moon](../../../sources/ML/converted/Moon/notebook.md) · [Fashion_MNIST](../../../sources/ML/converted/Fashion_MNIST/notebook.md) · [EMNIST](../../../sources/ML/converted/EMNIST/notebook.md)

### הכנת סביבת הפרק

<div class="code-panel" dir="ltr">

```python
import torch
from torch import nn
import numpy as np
import matplotlib.pyplot as plt
from torch.utils.data import DataLoader, TensorDataset

device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)
```

</div>


### מדוע צריך רשת? מגבלות הקו הישר

מחברת מגבלות הרגרסיה יוצרת 10,000 נקודות עם מגמה גלית ורעש. הנתונים מדומים; הכותרות year ו־temperature בגרף ממחישות יישום אפשרי, ואינן מדידות אקלים.

<div class="code-panel" dir="ltr">

```python
import numpy as np
from torch.utils.data import TensorDataset

x_array = np.linspace(1., 20., 10000)[:, None]
y_array = (0.02 * x_array
           + 0.3 * np.sin(x_array)
           + 0.1 * np.log(x_array)**2
           + 0.2 * np.random.randn(10000, 1))
x = torch.tensor(x_array, dtype=torch.float32)
y = torch.tensor(y_array, dtype=torch.float32)
loader = DataLoader(
    TensorDataset(x, y), batch_size=50, shuffle=True
)
```

</div>

TensorDataset מצמידה את שורת הקלט לשורת היעד שלה. אפשר להעביר אותה ל־DataLoader שכבר הכרנו.

כדי לתאר קשר לא לינארי, המחברת משתמשת בשתי שכבות חבויות של 64 יחידות וב־ReLU. זו **רגרסיה באמצעות רשת**: הפלט נשאר מספר חופשי, ולכן אין Sigmoid בסוף וההפסד הוא MSE.

<div class="code-panel" dir="ltr">

```python
model = nn.Sequential(
    nn.Linear(1, 64), nn.ReLU(),
    nn.Linear(64, 64), nn.ReLU(),
    nn.Linear(64, 1)
)
optimizer = torch.optim.Adam(
    model.parameters(), lr=0.001
)
for epoch in range(200):
    for x_batch, y_batch in loader:
        optimizer.zero_grad()
        loss = nn.functional.mse_loss(
            model(x_batch), y_batch
        )
        loss.backward()
        optimizer.step()
```

</div>

התאמה לנתוני האימון לבדה אינה מבטיחה הכללה. **נתוני ולידציה** משמשים לבחירת החלטות במהלך הפיתוח; נתוני בדיקה נשמרים להערכת התוצאה לאחר הבחירה.

### אותו מאגר, שני מודלים

כדי ללמוד מה מוסיפות השכבות החבויות, מאמנים תחילה `Linear(1,1)` עם MSE, ואחר כך את הרשת 1→64→64→1. מחברת המקור משתמשת ב־Adam בקצב 0.0001 במשך 100 תקופות עבור הקו, ובקצב 0.001 במשך 200 תקופות עבור הרשת. זו הדגמת יכולת ייצוג, אך הניסוי משנה גם את הגדרות האימון; השוואת ביצועים מבוקרת דורשת תנאי הערכה אחידים.

<div class="code-panel" dir="ltr">

```python
linear_model = nn.Linear(1, 1)
linear_optimizer = torch.optim.Adam(
    linear_model.parameters(), lr=0.0001
)
for epoch in range(100):
    for x_batch, y_batch in loader:
        linear_optimizer.zero_grad()
        loss = nn.functional.mse_loss(
            linear_model(x_batch), y_batch
        )
        loss.backward()
        linear_optimizer.step()
```

</div>

### לממש Dataset משלנו

במחברת מופיעה גם מחלקה השומרת את הנתונים ומחזירה זוג קלט־יעד. שלוש השיטות ממלאות תפקידים שונים: אתחול, מספר הדוגמאות, ושליפת דוגמה לפי אינדקס. היא שקולה לצורך הדוגמה לשימוש ב־TensorDataset, אך מאפשרת להוסיף בעתיד הכנה בזמן השליפה.

<div class="code-panel" dir="ltr">

```python
from torch.utils.data import Dataset

class TempDataset(Dataset):
    def __init__(self, x_array, y_array):
        self.x = torch.tensor(x_array, dtype=torch.float32)
        self.y = torch.tensor(y_array, dtype=torch.float32)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, index):
        return self.x[index], self.y[index]

dataset = TempDataset(x_array, y_array)
loader = DataLoader(dataset, batch_size=50, shuffle=True)
```

</div>

### להפריד רעש מקשר

הרשת יכולה לעקוב אחרי שינוי עקום, אבל אין הכרח שכל סטייה אקראית היא מידע שכדאי ללמוד. אם עקומת האימון ממשיכה לרדת בעוד שגיאת הוולידציה עולה, ייתכן שהרשת מתאימה את עצמה לרעש. לכן שומרים נתוני ולידציה לבחירת מספר התקופות והמבנה, ובודקים על קבוצת בדיקה נפרדת לאחר הבחירה.
