### ממספר לקטגוריה

ברגרסיה לינארית ניבאנו מספר חופשי. כעת נרצה להחליט בין שתי קטגוריות, המיוצגות על ידי 0 ו־1. **רגרסיה לוגיסטית**, הנקראת במצגות רגרסיה לוגית, היא מודל לסיווג בינארי.

נחשב תחילה צירוף לינארי של התכונות. לאחר מכן נפעיל פונקציה שממירה את התוצאה לערך שבין 0 ל־1.

### Sigmoid ופונקציות אקטיבציה

**פונקציית אקטיבציה** מופעלת על תוצאת חישוב של יחידת רשת. Sigmoid מחזירה `1 / (1 + exp(-z))`. ערך z גדול וחיובי מביא לתוצאה קרובה ל־1; ערך שלילי מאוד מביא לתוצאה קרובה ל־0; עבור z=0 מתקבלת 0.5.

<div class="code-panel" dir="ltr">

```python
import torch
from torch import nn

z = torch.tensor([-2., 0., 2.])
print(torch.sigmoid(z))
```

</div>

**פלט**

<div class="code-panel" dir="ltr">

```text
tensor([0.1192, 0.5000, 0.8808])
```

</div>

בסיווג הבינארי נפרש את התוצאה כאומדן להסתברות של קטגוריה 1. כדי לקבל החלטה אפשר לבחור סף של 0.5.

נפגוש גם **ReLU**, שמחזירה אפס עבור קלט שלילי ואת הקלט עצמו עבור קלט חיובי, ו־**Softmax**, שממירה ציונים לכמה קטגוריות להסתברויות שסכומן 1. נשתמש בהן כשנגיע לרשתות עמוקות ולסיווג של עשר ספרות.

### פונקציית הפסד לסיווג

**Binary Cross Entropy — BCE** משווה הסתברות בינארית לתווית 0 או 1. היא מענישה במיוחד תחזית בטוחה ושגויה. כאן משתמשים ב־Sigmoid ואחריה BCELoss; אין לעגל את ההסתברות לפני חישוב ההפסד.

<div class="code-panel" dir="ltr">

```python
loss_function = nn.BCELoss()
probability = torch.tensor([[0.8], [0.2]])
target = torch.tensor([[1.], [0.]])
loss = loss_function(probability, target)
```

</div>

### לחשב BCE ביד

הנוסחה לדוגמה אחת היא `−[y·ln(p)+(1−y)·ln(1−p)]`. כאשר y=1 נשאר רק ‎−ln(p); כאשר y=0 נשאר רק ‎−ln(1−p). אם התשובה הנכונה 1 והמודל נתן 0.8, ההפסד כ־0.223. אם נתן 0.2, ההפסד כ־1.609. תחזית 0.01, הבטוחה מאוד בתשובה השגויה, נותנת הפסד כ־4.605.

הדוגמה הקודמת, עם הסתברויות [0.8,0.2] ותוויות [1,0], נותנת אותו הפסד כ־0.223 לשתי הדוגמאות. הדיוק שלהן 100%, אבל ההפסד עדיין חיובי: המודל מסווג נכון בלי לתת ודאות מוחלטת. לכן דיוק והפסד מודדים דברים שונים.

אסור לעגל לפני ההפסד. עיגול מוחק את ההבדל בין 0.51 ל־0.99 ומנתק את מידע השיפוע שאנו צריכים ללמידה. בזמן האימון מעבירים הסתברות רציפה; בזמן ההחלטה בוחרים סף.

### עוד אקטיבציות במצגת

| פונקציה | פעולה | שימוש והדגש |
|---|---|---|
| Sigmoid | ממפה ל־0 עד 1 | הסתברות בינארית עם BCE |
| tanh | ממפה ל־‎−1 עד 1 | ייצוג חבוי או יעד מתאים; אינה קלט תקין ישיר ל־BCELoss |
| ReLU | מחזירה max(0,z) | אקטיבציה פשוטה בשכבות חבויות |
| Leaky ReLU | משאירה שיפוע קטן גם בצד השלילי | מאפשרת מעבר נגזרת גם עבור ערכים שליליים |
| Softmax | מנרמלת ציוני כמה קטגוריות יחד | הסתברויות שסכומן 1; נלמד בהמשך |

ב־Sigmoid הנגזרת היא `p(1−p)`: הגדולה ביותר סביב 0.5, וקטנה כאשר הפלט קרוב לקצוות. אם יחידות רבות נמצאות באזור רווי, שינויים בקלט כמעט אינם משנים את הפלט. זו אחת הסיבות להשתמש ב־ReLU בשכבות החבויות, בלי להסיק שהיא הבחירה הנכונה לכל פלט.

### גבול החלטה של מודל לינארי

כאשר הסף 0.5, הסיווג משתנה במקום שבו הציון הלינארי z שווה 0. בשני קלטים זהו הקו `w₁x₁+w₂x₂+b=0`. ה־Sigmoid מעקמת את הקשר בין הציון להסתברות, אך אינה הופכת את גבול ההחלטה של שכבה לינארית יחידה לגבול מפותל. נצטרך שכבות חבויות כדי להתמודד עם דוגמאות כגון שתי טבעות או שני סהרונים.

### דוגמת המחברת: נתוני Breast Cancer

המחברת משתמשת במאגר המובנה של scikit-learn: 569 דוגמאות, עם 30 תכונות מספריות לכל דוגמה ושתי תוויות. בדוגמה זו 0 מייצגת malignant ו־1 benign. אנחנו משתמשים בו ללימוד סיווג נתונים.

תחילה מפרידים את הדוגמאות לאימון ולבדיקה. נתוני הבדיקה לא ישמשו לעדכון המשקלים או לחישוב פרמטרי הנרמול.

<div class="code-panel" dir="ltr">

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

data = load_breast_cancer()
x_train, x_test, y_train, y_test = (
    train_test_split(
        data.data, data.target,
        test_size=0.2, random_state=2
    )
)
x_train = torch.tensor(x_train,
                       dtype=torch.float32)
x_test = torch.tensor(x_test,
                      dtype=torch.float32)
y_train = torch.tensor(y_train,
                       dtype=torch.float32)
y_test = torch.tensor(y_test,
                      dtype=torch.float32)
y_train = y_train.reshape(-1, 1)
y_test = y_test.reshape(-1, 1)
```

</div>

מתקבלות 455 דוגמאות אימון ו־114 דוגמאות בדיקה. התוויות הן float בצורת `[N,1]`, בהתאם לפלט הבינארי של המודל.

### הכנת הנתונים

<div class="code-panel" dir="ltr">

```python
minimum = x_train.min(dim=0).values
maximum = x_train.max(dim=0).values
scale = maximum - minimum
scale = torch.where(scale == 0, 1., scale)
x_train = (x_train - minimum) / scale
x_test = (x_test - minimum) / scale
```

</div>

גם נתון בדיקה עשוי לקבל ערך מחוץ לתחום 0–1, אם הוא מחוץ לטווח האימון. זו אינה סיבה לחשב עבורו נרמול אחר.

### בניית המודל ואימון

**Sequential** מפעילה שכבות לפי הסדר שבו הוגדרו. כאן השכבה הלינארית מקבלת 30 תכונות ומחזירה מספר אחד; Sigmoid ממירה אותו להסתברות.

נשתמש ב־**Adam**, אופטימייזר שמתאים את העדכונים לפי היסטוריית הנגזרות. ממשק השימוש בו דומה לזה של SGD.

<div class="code-panel" dir="ltr">

```python
model = nn.Sequential(
    nn.Linear(30, 1),
    nn.Sigmoid()
)
loss_function = nn.BCELoss()
optimizer = torch.optim.Adam(
    model.parameters(), lr=0.1
)
losses = []
for epoch in range(1000):
    optimizer.zero_grad()
    probability = model(x_train)
    loss = loss_function(probability, y_train)
    loss.backward()
    optimizer.step()
    losses.append(loss.item())
```

</div>

### בדיקת הסיווג

רק בשלב ההחלטה הופכים הסתברות לתווית. **Accuracy** היא שיעור הדוגמאות שסווגו נכון.

<div class="code-panel" dir="ltr">

```python
model.eval()
with torch.no_grad():
    probability = model(x_test)
    prediction = (probability >= 0.5).float()
    accuracy = (prediction == y_test)
    accuracy = accuracy.float().mean()
print(f"Accuracy: {accuracy.item():.4f}")
```

</div>

בתוצאה השמורה במחברת התקבל הדיוק הבא; הרצה חדשה עשויה לתת תוצאה מעט שונה.

**פלט**

<div class="code-panel" dir="ltr">

```text
Accuracy: 0.9649
```

eval מעבירה את המודל למצב הערכה; no_grad מפסיקה את מעקב הנגזרות. אלה שתי פעולות שונות, ונשתמש בשתיהן גם ברשתות הבאות.

### לא להסתפק באחוז הצלחה אחד

אפשר להפריד ארבע תוצאות: חיובי נכון, שלילי נכון, חיובי שגוי ושלילי שגוי. ״חיובי״ פירושו כאן התווית שהגדרנו כ־1, ולא תיאור מילולי טוב או רע. בדוגמת המאגר בפרק, 1 דווקא מייצגת benign.

<div class="code-panel" dir="ltr">

```python
with torch.no_grad():
    predicted = model(x_test).flatten() >= 0.5
    actual = y_test.flatten().bool()
    tp = (predicted & actual).sum().item()
    tn = (~predicted & ~actual).sum().item()
    fp = (predicted & ~actual).sum().item()
    fn = (~predicted & actual).sum().item()
print("TP, TN, FP, FN:", tp, tn, fp, fn)
```

</div>

הקוד מתאים לאחר השלמת ההמרה לטנסורים והאימון של הדוגמה שנבחרה. שינוי הסף משנה את היחס בין שני סוגי הטעויות; הוא אינו משנה את המשקלים. בחירת סף לפי נתוני בדיקה ואז דיווח עליהם כבדיקה בלתי תלויה תהיה שימוש חוזר במידע הבדיקה. לצורך בחירה במהלך הפיתוח משתמשים בוולידציה.


### דוגמה נוספת: Iris

למאגר Iris ארבע תכונות של פרח ושלושה מינים. במחברת הבינארית הופכים אותו לשאלה: **האם הפרח הוא ממין versicolor, שתוויתו 1?**

<div class="code-panel" dir="ltr">

