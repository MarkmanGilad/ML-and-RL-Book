# למידת מכונה ולמידת חיזוק באמצעות בניית משחקים

**ספר בעברית מאת גלעד מרקמן**

**ML & RL through Games · Machine Learning & Reinforcement Learning**

**[לקריאת הספר באתר ←](https://book.markman.co.il/)**

הספר מיועד לתלמידי כיתות י״א–י״ב במגמת הנדסת תוכנה, במסלול למידת מכונה ולמידת חיזוק. הוא מתקדם מיסודות פייתון ובניית משחקים אל רשתות נוירונים וסוכנים הלומדים מתוך תגמולים, ומשלב הסברים בעברית, דוגמאות קוד, איורים והדגמות.

**למידת חיזוק באמצעות משחקים (RL — Reinforcement Learning)** היא חלק מרכזי בספר: בונים סביבה וסוכן, מגדירים פעולות ותגמולים, ולומדים כיצד הסוכן משפר את החלטותיו מתוך התנסות במשחק. דוגמאות המשחקים מחברות בין ההסבר, האלגוריתם והקוד.

## מה לומדים בספר?

- **פייתון:** יסודות התכנות, מבני נתונים ועבודה עם נתונים.
- **בניית משחקים עם Pygame:** ציור, אירועים, אנימציה, ספרייטים והתנגשויות.
- **למידת מכונה עם PyTorch:** טנסורים, רשתות נוירונים ואימון מודלים.
- **למידת חיזוק:** סביבה וסוכן, MDP, תכנון דינמי, Monte Carlo, Temporal Difference, DQN ו־DDQN.

**[תוכן העניינים המלא](https://book.markman.co.il/#book-toc)**

## ML & RL through Games — a Hebrew Book

By **Gilad Markman**. A Hebrew textbook for grades 11–12, teaching Python, game development with Pygame, machine learning with PyTorch, and reinforcement learning through games.

**Reinforcement Learning (RL) through games is a central part of the book:** environments, agents, actions, rewards and policies, progressing through dynamic programming, Monte Carlo, Temporal Difference, DQN and DDQN.
