## ג.7 רגרסיה לינארית — משקל אחד

ברגרסיה לינארית מחפשים קו ישר שמתאר היטב את הקשר בין הקלט x לבין התוצאה y. הקו מתאר את מגמת הנתונים, ואינו חייב לעבור בכל הנקודות. בפרק זה נתחיל בישר העובר בראשית הצירים, שהמשוואה שלו היא **y = wx**; המשקל **w** הוא השיפוע שנלמד.

<!-- editorlm-source-ref: [sources/ML/pdf/5. רגרסיה לינארית.pdf#L8-L23] -->

### פונקציית ההפסד

נגדיר את ההפסד כריבוע ההפרש בין התחזית לתוצאה הרצויה:

$$
loss=(y_{predict}-y)^2=(wx-y)^2
$$

נצייר את ההפסד עבור שיפועים בין ‎−4 ל־9. כעת הציר האופקי הוא המשקל w, והציר האנכי הוא ההפסד.

```python
plt.xlabel("W")
```

### הגדרת המודל

המודל שלנו מחשב תחזית באמצעות הכפלת הקלט במשקל שנלמד. נגדיר את הנתונים כטנסורים. את המשקל שנאמן נאתחל ל־‎−1.5 עם `requires_grad=True`, ונבחר קצב למידה 0.01:

<div class="code-panel" dir="ltr">

```python
X = torch.tensor(2)
Y = torch.tensor(4.5)
W =  torch.tensor(-1.5, dtype=torch.float32, requires_grad=True)
learning_rate = 0.01

def model (X):
    return W * X
```

</div>


<!-- editorlm-source-ref: [sources/ML/converted/5_Linear_Regresion/notebook.md#L105-L121] -->

### פונקציית ההפסד והאופטימייזר

הפונקציה `loss` מחשבת את ריבוע השגיאה. האופטימייזר מעדכן את W:

<div class="code-panel" dir="ltr">

```python
def loss (Y_predict, Y):
    return (Y_predict - Y)**2  #(W * X - Y)**2

optim = torch.optim.SGD([W], lr=learning_rate) # W = W - grad * learning_rate
```

</div>


<!-- editorlm-source-ref: [sources/ML/converted/5_Linear_Regresion/notebook.md#L122-L134] -->

### לולאת האימון

בכל איטרציה מחשבים תחזית והפסד, מחשבים את הנגזרת, מעדכנים את המשקל ומאפסים את הנגזרת:

<div class="code-panel" dir="ltr">

```python
epochs = 300
for epoch in range(epochs):
    # Forward
    Y_predict = model(X)

    # Backward - calculate new grads
    l = loss(Y_predict, Y)
    l.backward()

    if (epoch) % 10 == 0:
        print (f"epoch={epoch} W={W:.3f}, Y_predict={Y_predict:.3f}, loss={l:.6f} grad={W.grad}")

    # Update weight
    optim.step()  # w = w - grad * LR

    # zero grads
    optim.zero_grad()
```

</div>

כעת נחשב את ממוצע ריבועי השגיאות — **MSE, Mean Squared Error**:

$$
loss=\frac{1}{n}\sum_{i=1}^{n}(wx_i-y_i)^2
$$

הריבוע נותן שגיאה לא־שלילית לכל נקודה. מסכמים את השגיאות ומחלקים במספר הנקודות; מחפשים את w שמקטין ממוצע זה.

<div class="code-panel" dir="ltr">

```python
W = torch.tensor(np.linspace(-4, 9, 100), dtype=torch.float32)

X = X.reshape(1,-1)
print(W.shape, X.shape)
loss = ((W@X-Y)**2).mean(1)
```

### הכנת הנתונים והמודל לאימון

```python
W = torch.tensor(8.0, requires_grad=True)
learning_rate = 0.01
print (X, Y, W)

def Model (X):
    return W * X
Y_predict = Model(X)
print (Y_predict)
```

### הגדרת ההפסד והאופטימייזר

נגדיר את ממוצע ריבועי השגיאות כפונקציה וניצור אופטימייזר עבור המשקל:

<div class="code-panel" dir="ltr">

```python
def Loss (Y_predict, Y):
    return ((Y_predict - Y)**2).mean() #((W * X - Y)**2).mean()

optimizer = torch.optim.SGD([W], lr=learning_rate) # W = W - W.grad * LR
```

</div>


<!-- editorlm-source-ref: [sources/ML/converted/5_Linear_Regresion/notebook.md#L364-L376] -->

### אימון המודל

נבצע 200 איטרציות על חמש הנקודות:

<div class="code-panel" dir="ltr">

```python
for epoch in range(200):

    # forward
    Y_predict = Model(X)

    # backward
    loss = Loss(Y_predict, Y)
    loss.backward()

    if epoch % 1 == 0:
        print(f"epoch= {epoch} W= {W.item():.3f} loss={loss.item():.3f} grad= {W.grad.item():.3f}")

    # Update weight
    optimizer.step()

    # zero grads
    optimizer.zero_grad()
```
