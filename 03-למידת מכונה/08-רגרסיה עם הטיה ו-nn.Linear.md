## ג.8 רגרסיה עם הטיה ו־nn.Linear

נמשיך בהתאמת קו ישר, והפעם נוסיף הטיה המאפשרת לו לחתוך את ציר y גם מחוץ לראשית. נתאים את הקו ל־100 נקודות. נבנה תחילה את המודל באמצעות פרמטרים שנגדיר בעצמנו, ולאחר מכן נשתמש ב־`torch.nn` להגדרת אותו סוג של מודל.

### הגדרת הפרמטרים, המודל, ההפסד והאופטימייזר

המודל הוא `y = wx + b`: המשקל w קובע את השיפוע, וההטיה b קובעת את החיתוך עם ציר y. לכן נגדיר שני פרמטרים, W ו־B, ונעביר את שניהם לאופטימייזר.

נוסיף גם רשימה בשם `losses` לשמירת ערכי ההפסד:

<div class="code-panel" dir="ltr">

```python
W = torch.tensor([0.0], requires_grad=True)
B = torch.tensor([0.0], requires_grad=True)

learning_rate = 0.01
epochs = 1000
losses = []

# design model
def Model(X):
    return W * X + B

#construct loss and optimizer
def Loss (Y_predict, Y):
    return ((Y_predict-Y)**2).mean()   # (W * X + B - Y)^2

# optimizer
optimizer = torch.optim.SGD([W, B], lr=learning_rate) # W = W - grad * LR / B -= grad * LR
```

</div>


<!-- editorlm-source-ref: [sources/ML/converted/5.2_Linear_Regresion/notebook.md#L254-L288] -->

### לולאת האימון

באימון נעדכן יחד את המשקל ואת ההטיה כדי להקטין את ההפסד. הלולאה `range(epochs+1)` מבצעת 1,001 איטרציות, ממספר 0 עד 1,000. בכל איטרציה נשמור את ההפסד ברשימה ונאפס את הנגזרות לאחר העדכון.

<div class="code-panel" dir="ltr">

```python
for epoch in range(epochs+1):
    # forward
    Y_predict = Model(X)

    # backward
    loss = Loss(Y_predict, Y)
    loss.backward()

    # Update parameters
    optimizer.step()  # W = W - grad * LR

    if epoch % 10 == 0:
        print(f"epoch= {epoch} loss={loss.item():.3f} ")

    losses.append(loss.item())

    # zero grads
    optimizer.zero_grad()
```

</div>


<!-- editorlm-source-ref: [sources/ML/converted/5.2_Linear_Regresion/notebook.md#L293-L321] -->

### שימוש ב־torch.nn

PyTorch מספקת מודל לינארי מוכן. `nn.Linear(1, 1, bias=True)` מגדירה קלט אחד ופלט אחד, עם משקל והטיה, ומבצעת את החישוב `wx+b`.

גם פונקציית ההפסד מוכנה: `nn.MSELoss()` מחשבת את ממוצע ריבועי השגיאות. השכבה יוצרת ומאתחלת את הפרמטרים בעצמה, ולכן מעבירים לאופטימייזר את `Model.parameters()`.

<div class="code-panel" dir="ltr">

```python
learning_rate = 0.1
epochs = 100
losses = []

# design model
Model = nn.Linear(1, 1, bias=True) # model = W * X + B

#construct loss and optimizer
Loss = nn.MSELoss() # Mean squared error

# init optimizer
optimizer = torch.optim.SGD(Model.parameters(), lr=learning_rate)
```

</div>


<!-- editorlm-source-ref: [sources/ML/converted/5.2_Linear_Regresion/notebook.md#L381-L446] -->
