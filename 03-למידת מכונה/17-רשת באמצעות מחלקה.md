### Softmax

בסיווג לכמה קבוצות, לכל קבוצה יש נוירון פלט. נרצה שהערך המתאים לקבוצה הנכונה יהיה גבוה מהערכים האחרים. Softmax הופכת את ציוני הפלט להסתברויות שסכומן 1.

החישוב לכל ציון הוא `exp(z_i) / Σ exp(z_j)`. לדוגמה, הציונים `[5.0, 2.5, 0.5]` נותנים בקירוב, לאחר עיגול לספרה אחת, `[0.9, 0.1, 0.0]`.

<!-- editorlm-source-ref: [sources/ML/pdf/9. רשת נורונים באמצעות מחלקה.pdf#L18-L35] -->

שתי דוגמאות נוספות, בערכים מעוגלים:

| ציוני הפלט | הסתברויות אחרי Softmax |
| --- | --- |
| `[1.3, 5.1, 2.2, 0.7, 1.1]` | `[0.02, 0.90, 0.05, 0.01, 0.02]` |
| `[5, 6, 11, 7]` | `[0.00, 0.01, 0.97, 0.02]` |

### One-hot encoding

בייצוג one-hot יש מקום לכל קבוצה: במקום של הקבוצה הנכונה מופיע 1, ובשאר המקומות 0. לדוגמה, בקידוד צבעים:

| צבע | Red | Yellow | Green |
| --- | --- | --- | --- |
| Red | 1 | 0 | 0 |
| Red | 1 | 0 | 0 |
| Yellow | 0 | 1 | 0 |
| Green | 0 | 0 | 1 |
| Yellow | 0 | 1 | 0 |

<!-- editorlm-source-ref: [sources/ML/pdf/9. רשת נורונים באמצעות מחלקה.pdf#L39-L53] -->

### Cross Entropy

Cross Entropy היא פונקציית הפסד המשווה את תחזית הרשת לתשובה הרצויה. לדוגמה, אפשר להשוות את ההסתברויות `[0.775, 0.116, 0.039, 0.070]` לתשובה `[1, 0, 0, 0]`. **ההפסד מודד את השגיאה; הוא אינו הופך את התחזית לווקטור one-hot.**

<!-- editorlm-source-ref: [sources/ML/pdf/9. רשת נורונים באמצעות מחלקה.pdf#L57-L60] -->

### פרמטרים ומחלקת הרשת

כל תמונה מכילה 28×28 פיקסלים, כלומר 784 ערכי קלט. נגדיר עשר קטגוריות, חמש תקופות אימון וקצב למידה 0.01:

<div class="code-panel" dir="ltr">

```python
input_size = 784 # 28x28
hidden_size = 200
num_classes = 10
epochs = 5
learning_rate = 0.01
# losses = torch.zeros(epochs*len(train_loader)//10)
```

</div>

<!-- editorlm-source-ref: [sources/ML/converted/9_ANN_Class/notebook.md#L131-L141] -->

המחלקה `ANN_Model` יורשת מ־`nn.Module`. ב־`__init__` מאתחלים את מחלקת הבסיס ומגדירים את השכבות; ב־`forward` מגדירים את מעבר הנתונים ביניהן. לרשת שתי שכבות נסתרות, בגודל 200 ו־100, ושכבת פלט בת עשרה נוירונים.

<div class="code-panel" dir="ltr">

```python
# Model = nn.Sequential(
#     nn.Linear(input_size,hidden_size,device=device),
#     nn.ReLU(),
#     nn.Linear(hidden_size, num_classes, device=device),
# )

class ANN_Model(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear1 = nn.Linear(input_size,hidden_size)
        self.linear2 = nn.Linear(hidden_size,100)
        self.linear3 = nn.Linear(100, num_classes)

    def forward(self, x):
        x = self.linear1(x)
        x = F.relu(x)         # torch.nn.functional as F
        x = self.linear2(x)
        x = F.relu(x)
        x = self.linear3(x)
        return x

Model = ANN_Model().to(device)
```

</div>

<!-- editorlm-source-ref: [sources/ML/converted/9_ANN_Class/notebook.md#L148-L176] -->

הקריאה `Model(images)` מפעילה את מעבר הנתונים שהוגדר ב־`forward`. אחרי שתי השכבות הראשונות מופעלת ReLU; השכבה האחרונה מחזירה עשרה ציונים גולמיים לכל תמונה.

### פונקציית הפסד ואופטימייזר

`nn.CrossEntropyLoss` כוללת את חישוב `LogSoftmax` ו־`NLLLoss`, ולכן אין להוסיף Softmax בסוף הרשת. נעביר אליה את ציוני הרשת ואת מספרי הספרות, ונשתמש ב־Adam לעדכון המשקלים.

<div class="code-panel" dir="ltr">

```python
Loss = nn.CrossEntropyLoss () # applies nn.LogSoftmax + nn.NLLLoss, No softmax in last layer

# init optimizer
# optim = torch.optim.SGD(Model.parameters(), lr=learning_rate,momentum=0.9)
optim = torch.optim.Adam(Model.parameters(), lr=learning_rate)
```

### אימון הרשת

בכל אצווה נפרוש את התמונות לשורות של 784 ערכים ונעביר אותן ואת התוויות להתקן. לאחר החישוב קדימה נחשב הפסד ונגזרות, נעדכן את המשקלים ונאפס את הגרדיאנטים.

<div class="code-panel" dir="ltr">

```python
n_total_steps = len(train_loader)

for epoch in range(epochs):
    for i, (images, lables) in enumerate(train_loader):

        # origin shape: [50, 1, 28, 28]
        # resized: [50, 784]
        images = images.reshape(-1, 28*28).to(device)
        lables = lables.to(device)    #no reshape for CrossEntropyLoss

        # forward
        Y_predict = Model(images)

        # backward
        loss = Loss(Y_predict, lables)
        loss.backward()

        # update wights
        optim.step()

        if i % 100 == 0:
            print(f"epoch= {epoch} i= {i+epoch * n_total_steps} loss={loss.item():.4f} ")

        # zero grads
        optim.zero_grad()
```

### בדיקת הדיוק

כעת נעבור על קבוצת הבדיקה, נבחר את הספרה בעלת הציון המרבי ונמנה כמה תחזיות תואמות לתוויות:

<div class="code-panel" dir="ltr">

```python
with torch.no_grad():
    n_correct = 0
    n_samples = 0
    for images, lables in test_loader:
        images = images.reshape(-1, 28*28).to(device)
        lables = lables.to(device)
        Y_predict = Model(images)
        __,y_predict_arg = torch.max(Y_predict,1)
        n_samples += lables.size(0)
        n_correct += (y_predict_arg == lables).sum().item()

    acc = 100 * n_correct / n_samples
    print(f'Accuracy of the network on the {n_samples} test images: {acc} %')
```

example_targets = example_targets.to(device)
example_predict_value, example_predict_arg = torch.max(Model(example_data.reshape(-1, 28*28)),1)
# print(example_predict_arg)
for i in range(len(example_data)):
    print ("Predict: ",example_predict_arg[i].item(), "target Label: ",example_targets[i].item() )
